# Big O Practice

A game for practicing Big O notation with real Python and C# snippets.

- **Practice**: relaxed, free hints that reveal one line's cost at a time, pick a topic.
- **Blitz**: 60 seconds, combos multiply your score, wrong answers cost 5 seconds.
- **Survival**: 3 lives, snippets get harder the longer you last.
- **Daily**: 10 questions, a new set every day, with a daily streak.

Snippets are a mix of hand-written ones and freshly generated ones, so questions keep changing.
After a miss, it shows every line's cost and builds the equation. XP, levels and badges are saved in your browser.

The Learn tab has the rules, a loop tracer, a "what happens when n doubles" table and a cheat sheet.

Live at **https://lab.joeyrockwood.fyi/big-o-practice/**. One static `index.html`, no build step, no dependencies.
