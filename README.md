# Big O Practice

Work out the Big O of real Python and C# snippets. Hints reveal one line's cost at a time, and after you answer it shows every line's cost and builds the equation.

Also includes a loop tracer (watch `i` change and count passes), a "what happens when n doubles" table, the rules, and a cheat sheet of common operation costs.

Live at **https://lab.joeyrockwood.fyi/big-o-practice/**. One static `index.html`, no build step, no dependencies.
